### Track B — Domain / Logic

**테스트 대상 (예정):** `LengthUnit.to_meter`, `Converter.convert_all`, `Registry.register`, 설정 로더  
**공통 RED 패턴:** 도메인 모듈·`units.json`·`ConfigError` 미구현 → `ImportError` 또는 `pytest.fail("RED: …")`

| Test ID | 함수 | Given / Then | Invariant |
|---------|------|--------------|-----------|
| **D-CNV-01** | `LengthUnit.to_meter(value)` (또는 `FeetUnit.to_meter`) | **Given:** `1` (feet) · **Then:** `0.3048` m (허용 오차 **ε = 1e-4**) · `abs(result - 0.3048) < ε` | `1 ft → m`는 **`1 / 3.28084`** (단일 상수); feet↔yard 직접 비율 **금지** |
| **D-CNV-02** | `Converter.convert_all(source_unit, value)` | **Given:** `meter`, `2.5` · **Then:** feet 결과 **`8.20210`** (소수 **5자리** 고정 표현) · `2.5 × 3.28084 = 8.2021` | 비율 **`3.28084`** 단일 출처; Mom Test **3.281 혼동 없음**; README 예시 `8.2`가 아닌 **TC로 고정한 5자리** |
| **D-CNV-03** | `Converter.convert_all` (feet → yard) | **Given:** 동일 입력값(예: `10` feet) · **Then:** `convert_all("feet", 10)["yard"]` == `convert_all("meter", to_meter(10))["yard"]` (또는 meter 경유 2단계 결과와 **완전 일치**) | feet→yard는 **`feet → meter → yard`**만; `3.281`·직접 ft/yd 상수 **금지** |
| **D-REG-01** | `Registry.register(name, meters_per_unit)` + `convert_all` | **Given:** `"cubit"`, **`0.4572`** (1 cubit = 0.4572 m) · **Then:** `convert_all("cubit", 1)["meter"] == 0.4572` (±ε) · cubit 입력 시 변환 **성공** | **OCP** — `converter.py` 수정 없이 등록만으로 변환 가능; 기존 meter/feet/yard TC **비파괴** |
| **D-CFG-01** | `load_units_config(path)` (또는 동등 로더) | **Given:** **깨진 JSON** 파일 경로(문법 오류·truncated) · **Then:** **`ConfigError`** (또는 프로젝트 정의 설정 예외) 발생; 변환기 인스턴스 **생성/사용 불가** | 비율은 JSON/YAML **외부 설정** 단일 출처; 손상 파일은 **조용한 fallback 금지** |

**Track B 수치 참조 (GREEN 설계용, RED에서 assert 금지)**

| 계산 | 값 |
|------|-----|
| 1 feet → meter | `1 / 3.28084 ≈ 0.304800987…` → TC 기대 **`0.3048`** (ε=1e-4) |
| 2.5 m → feet | `2.5 × 3.28084 = 8.2021` → 포맷 **`8.20210`** |
| D-CNV-03 예시 | `10 ft → m = 10/3.28084`, `→ yd = m × 1.09361`; 직접 `10/3` 등과 **불일치 시 meter 경유가 정답** |

**Track B RED 메모**

- D-CNV-01~03: `LengthUnit` / `Converter` / `units.json` **미존재** → 전부 RED.
- D-REG-01: `Registry.register` **미존재** → RED.
- D-CFG-01: `ConfigError`·로더 **미존재** → RED.
