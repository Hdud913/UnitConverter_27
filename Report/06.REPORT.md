## 1. 요약

`05.REPORT.md`의 **통합형 RED 스켈레톤**(`tests/test_cli.py`, `tests/test_converter.py`)을 **ECB(Entity · Control · Boundary) 구조**로 재구성했다. **Entity-Control-Boundary** 패턴을 `ARCHITECTURE.md`·`tdd-rules.mdc`에 반영하고, Test ID별 **9개 분리 테스트 파일** + **`docs/PRD.md`** 를 추가했다. 중간에 진행했던 `green` 브랜치 구현은 **롤백·삭제**하여 RED 시작 상태로 되돌렸다. `pytest tests/ -v` → **9 failed** (`ModuleNotFoundError` — `unit_converter/` 미착수).
